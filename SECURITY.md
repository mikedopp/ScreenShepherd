# Security

Please report security problems privately: open the [Security tab](https://github.com/mikedopp/ScreenShepherd/security) and choose **Report a vulnerability**. Only the maintainer can see it.

Please do not open a public issue for a security problem. Everything else belongs in the [issue tracker](https://github.com/mikedopp/ScreenShepherd/issues).

Supported: the latest release only.
