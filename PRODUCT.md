# Product

## Register

product

## Users

Windows power users and infrastructure operators working across multi-monitor desktops. They need to understand where application windows actually exist, identify the connected display hardware and active paths, recover stranded windows quickly, and distinguish the Windows display topology from the physical state of the panels.

## Product Purpose

Screen Shepherd inventories active displays, graphics adapter health, display-mode optimization, and normal top-level application windows. It maps real coordinates, identifies unreachable title bars, and provides deliberate rescue actions. Success means an operator can see the current desktop state at a glance, distinguish path, driver, and placement problems, and move a window safely without memorizing Windows keyboard rituals.

## Brand Personality

Direct, operational, technically precise, with restrained dry humor.

## Anti-references

Do not resemble a marketing landing page, a decorative gaming overlay, a generic system-cleaner utility, or a card-heavy AI dashboard. Avoid invented metrics, decorative motion, vague monitor labels, and visualizations that are not bound to live Windows coordinates.

## Design Principles

- Show spatial truth: use live physical-pixel coordinates and proportional display relationships.
- Status before action: expose active topology, visibility, rescue state, and target before movement controls.
- Make recovery deliberate: automatic rescue remains narrow; broad gather actions stay guarded.
- Preserve operator context: process, title, monitor, bounds, and visibility remain inspectable in both map and table forms.
- Keep the tool quiet: dense information, restrained color, and motion only when state changes.

## Accessibility & Inclusion

Use high-contrast dark surfaces, keyboard-accessible controls, visible focus states, status text in addition to color, readable tooltips, a tabular fallback for spatial data, and reduced-motion-safe interactions.
